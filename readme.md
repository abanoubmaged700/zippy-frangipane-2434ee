## 2. اللي اتعمل في V2
- **تصميم premium:** Playfair Display للعناوين + Inter للنص + Readex Pro للعربي، **كلها محلية** (مفيش طلبات لـ Google Fonts = أسرع وأحسن للخصوصية).
- **هيدر ثابت** بيتظلل لما تنزل، و**قائمة موبايل** بزرار، وتمييز القسم الحالي.
- **3 لغات كاملة:** إنجليزي (افتراضي) · ألماني · عربي بـ **RTL حقيقي** (كل الـ CSS بخصائص منطقية، فالاتجاه بيتقلب لوحده). اللغة بتتحفظ في المتصفح.
- **منيو رقمي تفاعلي:** 5 أقسام + فلتر، 13 طبق Sample، أسعار بالجنيه بتتنسّق حسب اللغة، وعلامات V/VG/GF (أمثلة لازم المطبخ يأكدها).
- **معرض صور** 8 أماكن + **Lightbox** (أسهم، Esc، ضغطة برّه = قفل)، و`loading="lazy"`.
- **نموذج حجز حقيقي:** اسم، تليفون، تاريخ (مش قبل النهارده)، وقت (من مواعيد الحجز، ولو النهارده بيرفض وقت فات)، عدد ضيوف، ملاحظات.
  - تحقق كامل بالأخطاء تحت كل حقل، بلغة الصفحة، والتركيز بيروح لأول حقل غلط.
  - بيولّد **رسالة واتساب مُرمّزة صح** بلغة الصفحة، مكتوب فيها بوضوح **"طلب حجز وليس حجزًا مؤكدًا"**.
  - **لو رقم المطعم مش متظبط:** مفيش إرسال، بيظهر تنبيه "Demo" وزرار نسخ الرسالة.
- **زرار واتساب عائم**، وقسم **تواصل** (عنوان، خريطة، مواعيد، تليفون، واتساب، إيميل، سوشيال)، و**فوتر** فيه "Website by Marsa Digital".
- **آراء الضيوف:** مكان فارغ واضح بدل آراء مخترعة.
- **SEO:** عناوين ووصف بتتغير مع اللغة، Open Graph، H1 واحد، تسلسل عناوين سليم. **مفيش Structured Data** لأن مفيش بيانات مطعم موثّقة.
- **وصول (Accessibility):** Skip link، labels لكل الحقول، focus واضح، تباين محسوب (أقل نص 5.15:1)، `prefers-reduced-motion`.
- **`noindex` مؤقت** عشان الديمو ميظهرش في جوجل. شيله لما الموقع يبقى لمطعم حقيقي.

> ملحوظة: الألوان في الطلب (#102E1E / #D4AF37 / #F8F5EF) قريبة جدًا من ألوان مرسى، لكن دي ألوان **المطعم** مش ألوان مرسى. مرسى ظاهرة بس في سطر "Website by Marsa Digital". (الطلب كان مكتوب فيه "Tourist Digital Solutions"؛ الاسم المعتمد دلوقتي Marsa Digital.)

## 5. النشر المجاني (الديمو العام)
الديمو جاهز للنشر كما هو: `demoMode: true`، وشريط "DEMO CONCEPT"، و"Demo website by Marsa Digital" في الفوتر مع رابط صفحة مرسى، وتنبيه في نموذج الحجز إنه مش بيبعت لأي مطعم، وسطر `noindex` عشان ميظهرش في جوجل.

**جهّز ملف النشر** (بيتعمل من جديد في أي وقت، وفولدر `dist/` مش داخل Git):
```powershell
powershell -ExecutionPolicy Bypass -File tools\build_demo_zip.ps1
```
بيطلع `dist/coastal-table-demo/` و`dist/coastal-table-demo.zip`. ولموقع عميل: `-Src Clients\<slug>\site -Name <slug>`. السكربت مبينشرش أي حاجة.

**اختار طريقة واحدة (كلها مجانية حسب شروط كل مزود وقت الاستخدام):**
- **أ. أسرع حاجة — رابط المعاينة:** https://claude.ai/artifact/Mb1rYANgo4YoCdP66zkByP → زر **Share** في الصفحة → اختار المشاركة العامة لو متاحة لحسابك. ده مش هوستنج حقيقي، بس كفاية تبعته لصاحب مطعم.
- **ب. Netlify Drop:** افتح app.netlify.com/drop واسحب فولدر `dist/coastal-table-demo`. ممكن يطلب تسجيل دخول مجاني عشان الرابط يفضل شغال. بيديك رابط `*.netlify.app`، وتقدر تغيّر الاسم من Site settings.
- **ج. Cloudflare Pages:** من لوحة Cloudflare: Workers & Pages → Create → Pages → Upload assets → ارفع `dist/coastal-table-demo.zip` أو الفولدر → اسم المشروع → Deploy. بيديك رابط `*.pages.dev`.

بعد النشر: افتح الرابط من موبايلك، وجرّب اللغات والمنيو ونموذج الحجز، واعمل QR للرابط:
```bash
node tools/make_qr.js https://YOUR-LINK Clients/coastal-table-demo/qr demo-qr
```
⚠️ **ممنوع شراء دومين أو تفعيل أي خطة مدفوعة من غير موافقة مكتوبة.**

## 6. تحويله لمطعم حقيقي (عدّل `js/config.js` بس)
1. `name`: اسم المطعم.
2. `whatsappNumber`: رقم المطعم دولي من غير `+`، مثال `"201XXXXXXXXX"`. **جرّب إن الرسالة بتوصل قبل التسليم.**
3. `contact`: العنوان، `mapsUrl` (رابط المطعم على Google Maps)، التليفون، الإيميل، السوشيال.
4. `hours`: المواعيد الحقيقية، و`slots` أوقات الحجز.
5. `menu`: الأقسام والأطباق والأسعار المعتمدة، وعلامات التغذية بعد تأكيد المطبخ.
6. `images`: حط صور المطعم في `assets/img/` واكتب مساراتها (بإذن المطعم).
7. `reviews`: آراء حقيقية بإذن أصحابها فقط، أو سيبها فاضية.
8. خلّي كل `verified: true` **بعد** ما المطعم يأكد البيانات (contact, hours, menu, images)، وبعدها `demoMode: false`.
9. في `index.html`: شيل سطر `noindex`، وعدّل العنوان والوصف، وضيف Structured Data بالبيانات الموثّقة.

النصوص العامة للواجهة في `js/i18n.js` (نفس المفتاح في الـ 3 لغات).
